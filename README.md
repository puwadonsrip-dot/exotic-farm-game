# Exotic Farm

เกมฟาร์มพิกเซลอาร์ต 2D มุมมองบนลงล่าง สร้างด้วย Unity

ปลูกพืช เลี้ยงสัตว์ในจินตนาการ รับเควสจาก NPC และดูแลฟาร์มให้โตขึ้นทีละวัน

---

## ระบบในเกม

| ระบบ | รายละเอียด |
|---|---|
| ทำไร่ | ไถดิน ปลูก รดน้ำ เก็บเกี่ยว — พืช 5 ชนิด (แครอท ข้าวโพด ข้าวสาลี มะเขือเทศ ฟักทอง) |
| กระเป๋า | Hotbar 8 ช่อง + กระเป๋าใหญ่ 4 แถบหมวดหมู่ (กด `I`) |
| ร้านค้า | ซื้อเมล็ด ไข่สัตว์ และสัตว์โตเต็มวัย / ขายผลผลิต |
| สัตว์ | 5 สายพันธุ์ ให้อาหาร เลี้ยงให้โต ผสมพันธุ์ และเก็บผลผลิต |
| เควส | เควสหลัก 9 ข้อจาก NPC |
| กลางวัน–กลางคืน | แสงเปลี่ยนตามเวลา มีเสาไฟ โคมไฟ และตะเกียงถือ |
| บันทึกเกม | เซฟ / โหลด และปุ่ม "เล่นต่อ" ที่หน้าเมนู |
| อื่นๆ | คัตซีนเปิดเกม ตั้งชื่อตัวละคร วาร์ประหว่างแผนที่ สมุดบันทึก (กด `J`) |

## ปุ่มควบคุม

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| `WASD` | เดิน |
| `คลิกซ้าย` | ใช้อุปกรณ์ในมือ / นอนบนเตียง |
| `1` – `8` | เลือกช่องของ (กดซ้ำ = วางของลง) |
| `E` | คุยกับ NPC / ให้อาหารสัตว์ / วาร์ป |
| `F` | เปิดร้านค้า |
| `I` | กระเป๋า |
| `J` | สมุดบันทึก |
| `H` | ดูปุ่มควบคุม |
| `Tab` | ปลด / ล็อกเมาส์ |
| `Esc` | เมนูตั้งค่า |

## เปิดโปรเจกต์นี้

ต้องใช้ **Unity 6000.3.19f1** (Unity 6.3 LTS) ขึ้นไป พร้อม Universal Render Pipeline (2D Renderer)

1. โคลนโปรเจกต์ลงเครื่อง
2. เปิดผ่าน Unity Hub → `Add project from disk`
3. รอ Unity สร้างโฟลเดอร์ `Library/` ใหม่ (ครั้งแรกใช้เวลาสักพัก — เป็นเรื่องปกติ)
4. เปิดซีนหลัก `Assets/project.unity` แล้วกด Play

ถ้าเมนูหรือ UI บางอย่างหาย ให้ไปที่ **Tools → Farming → ติดตั้งระบบ Farming** หนึ่งครั้ง

> วิธีอัปโหลดและดึงงานข้ามเครื่องแบบละเอียด อ่านได้ที่ [SETUP-GITHUB-TH.md](SETUP-GITHUB-TH.md)
