วิธีเปลี่ยนฟอนต์ทั้งเกม
=======================

เอาไฟล์ฟอนต์ .ttf มาวางในโฟลเดอร์นี้ แล้วตั้งชื่อว่า

    GameFont.ttf

เกมจะหยิบไปใช้เองทั้งเกมทันที ไม่ต้องแก้โค้ดตรงไหนเลย
(ถ้าไม่มีไฟล์นี้ เกมจะใช้ฟอนต์ Leelawadee UI ของ Windows แทน)


ฟอนต์ที่แนะนำ — ฟรี ใช้ในงานได้ มีภาษาไทยครบ
---------------------------------------------

โหลดจาก Google Fonts (กดปุ่ม "Get font" แล้ว "Download all")

    Kanit    https://fonts.google.com/specimen/Kanit
             เหลี่ยมๆ ดูโมเดิร์น เหมาะกับหัวข้อและ UI เกม

    Mitr     https://fonts.google.com/specimen/Mitr
             มนๆ อ่านง่าย เหมาะกับเกมน่ารักแนวฟาร์ม  ← แนะนำสำหรับเกมนี้

    Prompt   https://fonts.google.com/specimen/Prompt
             เรียบ สะอาด อ่านสบายตาที่สุด

    Sarabun  https://fonts.google.com/specimen/Sarabun
             ทางการหน่อย เหมาะถ้าอยากให้ดูสุภาพ


ขั้นตอน
-------

1. โหลดไฟล์ zip จากลิงก์ข้างบน แล้วแตกไฟล์
2. เลือกน้ำหนักที่ชอบ — แนะนำ Medium หรือ SemiBold
   (Regular จะบางไปหน่อยเวลาอยู่บนพื้นหลังสีเข้ม)
3. เปลี่ยนชื่อไฟล์เป็น GameFont.ttf
4. ลากมาวางในโฟลเดอร์นี้
5. กลับไปที่ Unity รอ import สักครู่ แล้วกด Play

ถ้าอยากใช้ชื่อไฟล์เดิมไม่ต้องเปลี่ยนชื่อก็ได้ โค้ดรองรับชื่อพวกนี้ไว้แล้ว:
Kanit-SemiBold, Kanit-Medium, Mitr-Medium, Prompt-Medium,
NotoSansThai-SemiBold, Sarabun-SemiBold


หมายเหตุเรื่องความคมชัด
-----------------------

ถ้าตัวหนังสือดูเบลอตอนกด Play ใน Unity — ส่วนใหญ่ไม่ได้ผิดที่ฟอนต์
แต่เป็นเพราะหน้าต่าง Game view เล็กกว่าขนาดจริงของเกม

UI ออกแบบไว้ที่ 1920x1080 ถ้า Game view กว้างแค่ ~970 พิกเซล
ตัวหนังสือจะถูกย่อลงครึ่งนึง เลยดูไม่คม

ลองกดปุ่ม Maximize บนแท็บ Game (หรือกด Shift+Space ตอนเมาส์อยู่เหนือ Game view)
หรือ Build ออกมาเล่นจริงแบบเต็มจอ จะเห็นว่าคมขึ้นมาก
