ฟอนต์ของเกม
===========

ตอนนี้ใช้ฟอนต์ **Mitr Medium** อยู่ (ไฟล์ GameFont.ttf ในโฟลเดอร์นี้)
เกมจะหยิบไปใช้เองทั้งเกม ไม่ต้องแก้โค้ดตรงไหน


อยากเปลี่ยนเป็นฟอนต์อื่น
------------------------

เอาไฟล์ .ttf ตัวใหม่มาวางทับ GameFont.ttf ในโฟลเดอร์นี้ได้เลย

**ระวังจุดที่พลาดง่ายที่สุด:** ไฟล์ที่โหลดจากเว็บมักเป็นไฟล์บีบอัด (.zip / .rar)
ต้อง **แตกไฟล์ออกมาก่อน** แล้วเอาไฟล์ .ttf ข้างในมาใช้
ถ้าแค่เปลี่ยนชื่อไฟล์ zip เป็น .ttf Unity จะอ่านไม่ออก แล้วตัวหนังสือในเกมจะหายหมด

วิธีเช็กว่าเป็นฟอนต์จริง: ดับเบิลคลิกไฟล์
  - เห็นตัวอักษรตัวอย่าง + ปุ่ม Install  = ฟอนต์จริง
  - เปิดด้วย WinRAR / 7-Zip             = ยังเป็นไฟล์บีบอัดอยู่

และเลี่ยงไฟล์ที่มีคำว่า **VariableFont** ในชื่อ — Unity อ่านไม่ได้
ถ้าในชุดมีโฟลเดอร์ชื่อ static ให้เข้าไปหยิบไฟล์ในนั้นแทน


ฟอนต์ไทยฟรีที่ใช้ได้ดี (Google Fonts)
--------------------------------------

  Mitr     มนๆ อ่านง่าย เหมาะกับเกมแนวน่ารัก   ← ตัวที่ใช้อยู่ตอนนี้
  Kanit    เหลี่ยม ดูโมเดิร์น
  Prompt   เรียบ สะอาด อ่านสบายตา
  Sarabun  ทางการ สุภาพ

แนะนำน้ำหนัก Medium หรือ SemiBold (Regular จะบางไปบนพื้นหลังเข้ม)


เรื่องความคมชัด
---------------

ถ้าตัวหนังสือดูเบลอตอนกด Play ใน Unity ส่วนใหญ่ไม่ได้ผิดที่ฟอนต์
แต่เป็นเพราะหน้าต่าง Game view เล็กกว่าขนาดจริงของเกม

UI ออกแบบไว้ที่ 1920x1080 ถ้า Game view กว้างแค่ ~970 พิกเซล
ตัวหนังสือจะถูกย่อลงครึ่งนึง

ลองกด Maximize ที่แท็บ Game (หรือ Shift+Space ตอนเมาส์อยู่เหนือ Game view)
หรือ Build ออกมาเล่นเต็มจอ จะคมขึ้นมาก
